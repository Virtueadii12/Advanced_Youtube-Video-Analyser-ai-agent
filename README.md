# 🎥 Advanced YouTube Video Analyser AI Agent

An AI-powered YouTube Video Analyzer built using Groq, Whisper AI, Agno Framework, Streamlit, and RAG architecture.

This application can deeply analyze YouTube videos, generate summaries, flashcards, MCQs, interview questions, timestamps, and provide an intelligent context-aware chatbot experience.

# 🚀 Features

✅ AI Video Analysis  
✅ Whisper AI Transcription  
✅ Smart Summaries
